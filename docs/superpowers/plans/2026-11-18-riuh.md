# Riuh Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Kuis ice breaking dua tombol: layar presenter (host) menampilkan soal, HP/laptop peserta menjadi kontroler, tersambung lewat server realtime.

**Architecture:** Logika game sepenuhnya di modul murni (`src/game.ts`, `src/views.ts`, `src/rooms.ts`, `src/sets.ts`) yang menerima `now: number` sebagai argumen sehingga bisa diuji tanpa timer. `server.ts` (Bun + Socket.IO) hanya meneruskan event, menjalankan `tick` tiap 250 ms, dan mengirim view per klien. Frontend HTML/CSS/JS biasa di `public/`, tanpa build step.

**Tech Stack:** Bun 1.3.x, TypeScript, socket.io 4.x (server) + client bundle dari `/socket.io/socket.io.js`, `qrcode` (SVG), `bun test`.

**Spec:** `docs/superpowers/specs/2026-11-18-riuh-design.md`

## Global Constraints

- Semua teks UI bahasa Indonesia, tanpa emoji.
- Tidak meniru visual/merek produk di rekaman inspirasi.
- `READING_MS = 3000`; waktu jawab default 10 detik, rentang 5 sampai 30.
- `MAX_PLAYERS = 60` per ruang; `MAX_ROOMS = 20`; `MAX_ROOMS_PER_IP = 3`.
- `HOST_GRACE_MS = 10 menit`; `ROOM_TTL_MS = 3 jam`.
- Nama maks 16 karakter setelah trim; kembar diberi akhiran ` 2`, ` 3`, ...
- Kode ruang 4 huruf kapital dari alfabet tanpa `I`, `O`, `L`.
- Skor Benar/Salah: benar = `500 + round(500 * (1 - elapsed/limit))`, minimum 500, maksimum 1000; salah/tidak menjawab = 0. Pilih Satu tanpa skor.
- Seri: total `correctMs` (jumlah waktu jawab pada soal tf yang benar) lebih kecil di atas; masih seri, `joinOrder` lebih kecil di atas.
- Kontroler harus jalan di Android Chrome 2020+ dan iOS Safari 15+: tanpa sintaks JS di atas ES2020, tanpa CSS `:has()`.
- Pesan commit bahasa Inggris.

## Review Focus

1. Pemain memuat ulang halaman atau HP tidur di tengah soal: harus kembali dengan skor dan jawaban soal itu tetap tercatat; tidak boleh menjawab dua kali. (Task 2 & 3 tes `rejoin keeps score and current answer`.)
2. Pemain yang terputus tidak boleh menahan soal: "semua sudah menjawab" hanya menghitung yang terhubung. (Task 3 tes `disconnected players do not block early end`.)
3. Host memuat ulang halaman: kembali ke ruang yang sama, bukan ruang baru. (Task 5 tes `findByHostToken`.)
4. Set soal JSON rusak (field hilang, `time` di luar rentang, tipe salah): set dilewati, server tetap jalan. (Task 1 tes validasi.)
5. Nama berisi HTML (`<b>x</b>`): tampil sebagai teks, bukan markup. (Task 7 & 8: semua render pakai `textContent`, dicek manual di Task 9.)

### Task 3: Alur soal, jawaban, skor (`src/game.ts` bagian 2)

**Files:**
- Modify: `src/game.ts`
- Test: `tests/game-flow.test.ts`

**Interfaces:**
- Produces:
  ```ts
  export function selectSet(room: Room, set: QuestionSet): void            // hanya di lobby
  export function startGame(room: Room, now: number): boolean              // butuh set dan >= 1 pemain aktif
  export function tick(room: Room, now: number): boolean                   // true bila fase berubah
  export function submitAnswer(room: Room, playerId: string, choice: Choice, now: number): { ok: true } | { ok: false; error: 'NOT_OPEN' | 'ALREADY' | 'UNKNOWN_PLAYER' }
  export function endQuestion(room: Room, now: number): void               // answering -> result, hitung skor
  export function advance(room: Room, now: number): boolean                // tombol Lanjut host
  export function currentQuestion(room: Room): Question | null
  export function scoreFor(elapsedMs: number, limitMs: number): number
  export function leaderboard(room: Room): Player[]
  export function resetForReplay(room: Room): void                         // skor 0, fase lobby, pemain tetap
  ```
- Transisi:
  - `startGame` / `advance` ke soal berikutnya: fase `reading`, `phaseEndsAt = now + READING_MS`, `answers` dikosongkan, `lastGain` semua 0.
  - `tick` di `reading` saat `now >= phaseEndsAt`: fase `answering`, `openedAt = now`, `phaseEndsAt = now + timeSec*1000`.
  - `tick` di `answering` saat `now >= phaseEndsAt`: `endQuestion`.
  - `submitAnswer` diterima hanya di `answering`; `ms = now - openedAt`. Bila semua pemain terhubung dan tidak di-kick sudah menjawab: `endQuestion` langsung.
  - Pemain yang gabung saat `reading`/`answering` (baru, bukan rejoin) mendapat `Player.lateFor = room.qIndex`: jawabannya untuk soal itu ditolak `NOT_OPEN`, dan ia tidak dihitung dalam "semua sudah menjawab". Tambahkan field `lateFor: number | null` ke `Player` (Task 2) dan tes `late joiner waits for next question`.
  - `endQuestion`: untuk `tf`, pemain benar dapat `scoreFor(ms, limit)`, `correctMs += ms`, `lastGain` diisi. Fase `result`.
  - `advance` dari `result`: bila soal `tf` -> `board`; selain itu ke soal berikutnya atau `end`. Dari `board`: soal berikutnya atau `end`. Dari `answering`: sama dengan "Akhiri soal sekarang" (`endQuestion`). Fase lain: `false`.

- [ ] **Step 1: Tes gagal** (semua dengan `now` buatan):
  - `answers rejected during reading` -> `NOT_OPEN`.
  - `reading opens after 3000 ms` : `tick(room, t0+2999)` tetap `reading`, `tick(room, t0+3000)` -> `answering`.
  - `second answer rejected` -> `ALREADY`.
  - `ends early when all connected answered`.
  - `disconnected players do not block early end`.
  - `ends when time runs out`.
  - `scoreFor`: `(0, 10000) === 1000`, `(5000, 10000) === 750`, `(10000, 10000) === 500`, `(12000, 10000) === 500`.
  - `pick question gives no score and skips board`.
  - `tf result goes to board then next question`; `last question advances to end`.
  - `leaderboard tie broken by correctMs then joinOrder`.
  - `resetForReplay zeroes scores and returns to lobby`.
- [ ] **Step 2:** FAIL.
- [ ] **Step 3:** Implementasi.
- [ ] **Step 4:** PASS (semua tes).
- [ ] **Step 5:** Commit `feat: question flow with reading phase and scoring`.

### Task 6: Server realtime (`server.ts`)

**Files:**
- Create: `server.ts`
- Test: `tests/server.test.ts` (integrasi dengan `socket.io-client`, `bun add -d socket.io-client`)

**Interfaces:**
- Consumes: semua modul Task 1-5.
- Rute HTTP: `/` dan `/host` -> `public/host.html`; `/p` dan `/p/:code` -> `public/play.html`; `/qr/:code.svg` -> SVG QR dari `PUBLIC_URL + '/p/' + code`; file statis lain dari `public/`. `PORT` (default 3030), `HOST` (default `0.0.0.0`), `PUBLIC_URL` (default `http://localhost:PORT`).
- IP klien: header `x-forwarded-for` (bagian pertama) bila ada, selain itu alamat socket.
- Event klien -> server (semua dengan callback `ack`):
  - Host: `host:create` -> `{ ok, hostToken, code } | { ok:false, error }`; `host:resume {hostToken}`; `host:selectSet {setId}`; `host:start`; `host:advance`; `host:kick {playerId}`; `host:replay`.
  - Pemain: `player:join {code, name, token?}` -> `{ ok, token, playerId } | { ok:false, error: 'NO_ROOM'|'NAME_EMPTY'|'FULL'|'KICKED' }`; `player:answer {choice}`.
- Server -> klien: `host:view` (HostView) ke socket host; `player:view` (PlayerView) ke tiap pemain; `player:kicked`; `sets` (daftar `{id,title,count}`) ke host saat create/resume.
- Socket room Socket.IO: `host:CODE` dan `player:<playerId>`. Setelah tiap event yang mengubah state dan tiap `tick` yang mengembalikan `true`, kirim ulang semua view ruang itu. Selama `reading`/`answering`, host juga menerima view tiap 1 detik untuk hitung mundur.
- Interval 250 ms: `tick` semua ruang; interval 60 detik: `sweep`.
- Disconnect host -> `hostLeft`; disconnect pemain -> `setConnected(false)` lalu cek early end lewat `tick`.
- [ ] **Step 1: Tes gagal:** jalankan server di port acak; host `host:create` -> dapat kode; dua pemain `player:join`; `host:selectSet` + `host:start`; setelah >3 detik `player:answer` dari keduanya -> host menerima `host:view` fase `result`; `player:join` dengan kode salah -> `NO_ROOM`.
- [ ] **Step 2:** FAIL. **Step 3:** Implementasi (ekspor `startServer(port): {close()}` agar bisa dites; jalan otomatis bila `import.meta.main`). **Step 4:** PASS.
- [ ] **Step 5:** Commit `feat: realtime server`.
